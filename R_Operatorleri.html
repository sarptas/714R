R Operatörleri

R'deki operatörler, değişkenler ve değerler (operandlar) üzerinde işlem yapan sembollerdir. Matematiksel hesaplamalar, mantıksal karşılaştırmalar, atamalar ve diğer işlemleri verimli bir şekilde gerçekleştirmenizi sağlar.

Aritmetik Operatörler

Aritmetik operatörler, sayısal değerler veya vektörler üzerinde matematiksel işlemler gerçekleştirir. R'de vektörlerle çalışırken bu işlemler eleman bazında uygulanır.

1. Toplama (+)

Her iki operandın (terimin) değerleri toplanır.

a <- c(1, 0.1)
b <- c(2.33, 4)
print(a + b)
Çıktı
[1] 3.33 4.10

2. Çıkarma (-)

İkinci operandın değerleri birinciden çıkarılır.

a <- 6
b <- 8.4
print(a - b)
Çıktı
[1] -2.4

3. Çarpma (*)

Vektörlerin karşılık gelen elemanları veya tamsayılar '*' operatörü ile çarpılır.

print(3*4)
b = c(4,4)
c = c(5,5)
print(b * c)
Çıktı
[1] 12
[2] 20 20

4. Bölme (/)

Birinci operand ikinci operanda '/' operatörü ile bölünür.

a <- 10
b <- 5
print(a / b)
Çıktı
[1] 2

5. Üs Alma (^)

Birinci operand ikinci operandın üssü olarak alınır.

a <- 4
b <- 5
print(a ^ b)
Çıktı
[1] 1024

6. Mod Alma (%%)

Birinci operandın ikinci operanda bölümünden kalanını döndürür.

a <- c(2, 22)
b <- c(2,4)
print(a %% b)
Çıktı
[1] 0 2

Mantıksal Operatörler

R'deki mantıksal operatörler, operandlar arasında belirtilen operatöre göre eleman bazında karar işlemleri yapar ve True veya False boolean değeri döndürür. Sıfır olmayan herhangi bir tamsayı değeri TRUE kabul edilir (karmaşık veya gerçek sayı olsa bile).

1. Eleman Bazında VE (&)

Her iki operand da True ise True döndürür.

a <- c(TRUE, 0.1)
b <- c(0,4+3i)
print(a & b)
Çıktı
[1] FALSE  TRUE

2. Eleman Bazında VEYA (|)

Operandlardan en az biri True ise True döndürür.

a <- c(TRUE, 0.1)
b <- c(0,4+3i)
print(a | b)
Çıktı
[1] TRUE TRUE

3. DEĞİL (!)

Unary bir operatör olup operandın elemanlarının durumunu tersine çevirir.

a <- c(0, FALSE)
print(!a)
Çıktı
[1] TRUE TRUE

4. Kısa Devre VE (&&)

Operandların ilk elemanlarının her ikisi de True ise True döndürür.

a <- c(TRUE, 0.1)
b <- c(0,4+3i)
print(a[1] && b[1])
Çıktı
[1] FALSE

5. Kısa Devre VEYA (||)

Operandların ilk elemanlarından herhangi biri True ise True döndürür.

a <- c(TRUE, 0.1)
b <- c(0,4+3i)
print(a[1] || b[1])
Çıktı
[1] TRUE

İlişkisel Operatörler

R'deki ilişkisel operatörler, operandların karşılık gelen elemanları arasında karşılaştırma yapar. Birinci operand ikinciye göre ilişkiyi sağlıyorsa boolean TRUE değeri döndürür. TRUE değeri her zaman FALSE'tan büyük kabul edilir.

1. Küçüktür (<)

Birinci operandın ilgili elemanı ikinci operandın elemanından küçükse TRUE döndürür.

a <- c(TRUE, 0.1, "apple")
b <- c(0, 0.1, "bat")
print(a < b)
Çıktı
[1] FALSE FALSE  TRUE

2. Küçük veya Eşittir (<=)

Birinci operandın ilgili elemanı ikinci operandın elemanına küçük veya eşitse TRUE döndürür.

a <- c(TRUE, 0.1, "apple")
b <- c(TRUE, 0.1, "bat")
c <- as.character(a)
d <- as.character(b)
print(c <= d)
Çıktı
[1] TRUE TRUE TRUE

3. Büyüktür (>)

Birinci operandın ilgili elemanı ikinci operandın elemanından büyükse TRUE döndürür.

a <- c(TRUE, 0.1, "apple")
b <- c(TRUE, 0.1, "bat")
print(a > b)
Çıktı
[1] FALSE FALSE FALSE

4. Büyük veya Eşittir (>=)

Birinci operandın ilgili elemanı ikinci operandın elemanına büyük veya eşitse TRUE döndürür.

a <- c(TRUE, 0.1, "apple")
b <- c(TRUE, 0.1, "bat")
print(a >= b)
Çıktı
[1]  TRUE  TRUE FALSE

5. Eşit Değildir (!=)

Birinci operandın ilgili elemanı ikinci operandın elemanına eşit değilse TRUE döndürür.

a <- c(TRUE, 0.1, 'apple')
b <- c(0, 0.1, "bat")
print(a != b)
Çıktı
[1]  TRUE FALSE  TRUE

Atama Operatörleri

R'deki atama operatörleri, çeşitli veri nesnelerine (tamsayı, vektör, fonksiyon vb.) değer atamak için kullanılır. Atanan değerler değişken isimleri ile saklanır.

1. Sol Atama (<- , <<- , =)

Bir vektöre değer atar.

vec1 = c("ab", TRUE)
print(vec1)
Çıktı
[1] "ab"   "TRUE"

2. Sağ Atama (-> , ->>)

Bir vektöre değer atar.

c("ab", TRUE) ->> vec1
print(vec1)
Çıktı
[1] "ab"   "TRUE"

Çeşitli Operatörler

R'deki çeşitli (miscellaneous) operatörler, dizilerin oluşturulması ve vektör atamalarının (sol veya sağ yönlü) yapılmasını sağlar.

1. %in% Operatörü

Bir elemanın bir listeye ait olup olmadığını kontrol eder; varsa TRUE, yoksa FALSE döndürür.

val <- 0.1
a <- c(TRUE, 0.1, "apple")
print(val %in% a)
Çıktı
[1] TRUE

2. %*% Operatörü (Matris Çarpımı)

%*% operatörü matris çarpımı gerçekleştirir.

  • Birinci matrisin sütun sayısı ikinci matrisin satır sayısına eşit olmalıdır.
  • Eğer A (r × c) ve B (c × r) ise sonuç (r × r) olur.
mat = matrix(c(1,2,3,4,5,6), nrow=2, ncol=3)
print(mat)
print(t(mat))
pro = mat %*% t(mat)
print(pro)
Çıktı
     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6
     [,1] [,2]
[1,]    1    2
[2,]    3    4
[3,]    5    6
     [,1] [,2]
[1,]   35   44
[2,]   44   56
